# Ultimate Trainer

This is the public download page for Ultimate Trainer.

## Download

Open the [Releases page](https://github.com/ZacharyChapman1996/Ultimate-Trainerv1/releases) and download **UltimateTrainerSetup.exe** from the latest release. Run the installer to install or update Ultimate Trainer.

The release also includes `SHA256SUMS.txt`, which contains the installer's SHA-256 checksum so you can verify the download.

## Updates

Ultimate Trainer checks this repository for updates from inside the app. New test builds are published as prereleases while they are being tested. The updater-test release uses the tag `ultimate-trainer-updater-test` and is updated in place, so the same release is refreshed rather than creating a new download entry for every build.
